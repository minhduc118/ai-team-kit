Giải pháp lưu trữ Knowledge Base tập trung, giao tiếp qua giao thức MCP. Các AI Agents (Cursor, Windsurf) bị ràng buộc bởi các quy định nghiêm ngặt, tự động đọc hiểu dự án và sinh tài liệu chuẩn xác 100%.

🛠️ Hướng Dẫn Cài Đặt

Server hỗ trợ tự động chuyển đổi giữa Local (Stdio) và Remote (HTTP) dựa vào biến môi trường.

Chế độ Local (Khuyên dùng cho IDE)

Tốc độ siêu nhanh, đọc ghi file trực tiếp trên ổ cứng máy bạn.

{
  "mcpServers": {
    "team-kb": {
      "command": "node",
      "args": ["/path/to/dist/index.js"]
    }
  }
}

Chế độ Remote (Render/Cloud)

Cần cấp biến môi trường GITHUB_TOKEN, GITHUB_OWNER, GITHUB_REPO để tự động ghi file qua API.

{
  "mcpServers": {
    "team-kb": {
      "type": "streamable-http",
      "serverURL": "https://your-app.onrender.com/mcp"
    }
  }
}
